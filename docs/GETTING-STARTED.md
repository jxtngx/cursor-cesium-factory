# Getting started

1. Open this repo in Cursor.
2. Run `@init-globe`.
3. Answer runtime (CesiumJS / Unreal / Unity) then data host (ion / self-hosted / local).
4. Approve the technical-requirements plan.
5. Let `@chief-architect` → `@cesium-sme` → `@scrum-master` staff tickets.

Do not create a Viewer until the spec is approved.

JS tracks need Node and a Cesium ion token only if TRACK is `js-ion`.
Self-hosted and local tracks need a tileset URL or a fixture in-repo (small, public-domain).
